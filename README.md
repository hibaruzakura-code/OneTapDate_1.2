# ワンタップデイト（GitHub でビルドする手順）

1. GitHub で New repository を作る（Private でも可）
2. このフォルダの中身をすべてアップロードする（.github フォルダも必ず含める）
3. Actions タブで Build APK が自動で動く（数分）
4. 緑のチェックになったら、実行結果の下の Artifacts から DateButton-apk をダウンロード
5. APK をスマホに入れ、提供元不明のアプリを許可してインストール
6. アプリを開き「ユーザー補助の設定を開く」→「ワンタップデイト」をオン
7. 画面上部のクイック設定を編集し、「ワンタップデイト」のタイルを追加（ボタンの表示切替用）

赤い × になったら、ログの「e: file」で始まる行を確認する。
